# Surface: the app (src/App.jsx, all three modes)

Mode: Operate. Audience: the general Brazilian public, phone or desktop, one short task per visit (make or read one code, export, leave). Constraints: client-side only, pt-BR copy by default with an English toggle, the exported code must scan.

Chosen direction: the category standard (standing exit), taken deliberately by the user on 2026-11-27. Craft bar: QRCode Monkey and QR Code Generator (qr-code-generator.com), executed at full fidelity, no irony, no smuggled quirk.

Memorable moment: the code updates live beside the settings and stays in view while you adjust them; one blue button downloads it.

Unresolved: app icons (favicon, logo192/512) predate the redesign and still carry the old indigo; replace when an icon is produced.

## Direction contract

THESIS: The QR and barcode generator a Brazilian already knows how to use, preview beside settings and one blue action, built to the finish of the category leaders. It refuses the previous look: indigo-to-violet gradients, emoji headings, cards nested in cards, bouncy motion.

OWN-WORLD: Cool grey ground, white panels with 1px hairline borders and 12px radius, slate ink, a single blue (#2563EB) reserved for the primary action, selection and focus. Inter at a tight fixed rem scale; tabular monospace only for keys and digits. Native-feeling controls: segmented radios, native selects, a real colour field. Dark theme mirrors it on slate.

STORY: The visitor sees what the tool does, types or pastes content, watches the code change, adjusts colours, style or format with the preview always visible, and downloads or copies. In the scanner, they point the camera or send a photo and get readable content, with NF-e keys decoded and checked.

FIRST VIEWPORT: Header with the name, history and theme. A short h1 with a one-line promise (free, no sign-up, nothing leaves the device). A centred three-way mode switch. Desktop: left column, the code on a neutral stage with format choice, Baixar (primary, blue) and Copiar imagem directly under it, sticky while the right column scrolls; right column, Conteúdo first, then the settings. Mobile: content, then the preview with its download, then settings.
